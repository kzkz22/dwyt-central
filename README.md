# dwyt-central

A **dwyt** központja: webes felület, belépés (Google + meghívás), felhasználónként külön könyvtár, keresés, postaláda, munkasor és MCP. A számítást nem maga végzi: a munkákat a felhasználók saját futtatói ([dwyt-runner](https://github.com/kzkz22/dwyt-runner)) kérik el és adják le.

- Terv és döntések: [dwyt-docs/docs/terv.md](https://github.com/kzkz22/dwyt-docs/blob/main/docs/terv.md)
- Központ–futtató protokoll: [dwyt-docs/docs/protokoll.md](https://github.com/kzkz22/dwyt-docs/blob/main/docs/protokoll.md)
